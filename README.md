## 项目简介

公文排版助手是一款 Windows 桌面便携软件，用于将导入或粘贴的文字内容按公文排版参数重新整理，并导出为 `.docx` 文档。软件面向日常公文、通知、汇报材料、总结材料等场景，重点解决“内容已经写好，但格式需要统一”的重复排版工作。

- 推荐分发附件名：`公文排版助手V1_3_2-windows-portable.zip`

## 核心功能

- 导入 `.docx` 和 `.txt` 文档。
- 在编辑区直接粘贴、输入和修改文字。
- 导入文档后自动清除原格式，仅保留文字和段落结构。
- 自动识别文档标题、一级标题、二级标题和正文。
- 设置页边距、固定行距、字体和字号。
- 正文导出为两端对齐。
- 文档标题与后续正文或标题之间自动空一行，空行使用正文段落格式。
- 中文语境自动使用中文标点，英文语境自动使用英文标点。
- 可检查正文空格，导出时智能删除中文间及中文标点周围的多余空格，同时保留英文、数字和单位所需空格。
- 支持“重点字段”设置，可为指定文字单独设置字体、字号和加粗。
- 支持加载 Windows 本地字体，并可从软件字体下拉菜单中删除不需要显示的字体选项。
- 支持保存当前参数为默认模板。
- 支持保存默认导出文件夹。
- 导出排版后的 `.docx` 文档。

## V1.3.2 更新摘要

- 版本号、窗口标题、应用版本和打包产物统一更新为 V1.3.2 / `V1_3_2`。
- “段落设置”新增“检查正文空格”选项，默认开启并记住用户选择。
- 导出时仅清理自动识别为正文的段落，不改动编辑区、文档标题和各级标题。
- 中文字符之间及中文标点周围的空格会被删除，其他连续空白压缩为一个半角空格。
- 新增正文空格清理、模板兼容、重点字段和 `.docx` 输出自动化测试。

## V1.3.1 更新摘要

- 版本号、窗口标题、应用版本和打包产物统一更新为 V1.3.1 / `V1_3_1`。
- 新增“重点字段”功能，默认字段为“分析认为”“一是”“二是”“三是”“四是”“五是”。
- 重点字段支持新增、删除、保存，并记住用户上次设置。
- 重点字段可统一设置专用字体、字号和是否加粗。
- 默认重点字段格式调整为 `仿宋`、`小二`、加粗。
- 用户修改排版参数后，软件会自动记住当前设置，下次启动自动恢复。
- 输出正文段落改为两端对齐。
- 输出文档标题后自动增加一个空白正文格式段落。
- 优化中英文标点自动转换规则，中文句子中夹带英文产品名时，句末标点仍按中文语境处理。
- 默认排版字体调整为：文档标题 `黑体`，一级标题 `黑体`，二级标题 `黑体`，正文 `仿宋`。
- 字体由用户电脑本地字体提供，导出的 `.docx` 写入真实字体名称。
- 加载本地字体面板直接读取 Windows 字体列表，删除字体仅隐藏软件下拉菜单选项。
- 取消历史字体别名替换规则，`方正小标宋简体`、`方正小标宋_GBK`、`楷体_GB2312`、`仿宋_GB2312` 会按真实字体名显示、加载和导出，不再自动替换为 `黑体` 或 `仿宋`。
- 字体加载和删除弹窗列表样式统一为浅色背景、浅绿边框和一致的字体风格。
- 打包输出目录改为 `dist`，构建脚本会清理旧版本目录和运行配置目录。

## 默认排版参数

- 上边距：36 毫米
- 下边距：36 毫米
- 左边距：27 毫米
- 右边距：27 毫米
- 固定行距：30 磅
- 正文空格检查：开启
- 文档标题：黑体，二号
- 一级标题：黑体，小二
- 二级标题：黑体，小二
- 正文：仿宋，小二
- 重点字段：仿宋，小二，加粗

> 说明：`黑体`、`仿宋`、`宋体` 等为 Windows 常见系统字体。若用户加载 `方正小标宋简体`、`方正小标宋_GBK`、`楷体_GB2312`、`仿宋_GB2312` 等本机字体，软件会保留真实字体名，不再做别名替换。

## 普通用户运行方式

1. 获取 Windows 便携版压缩包。
2. 解压到本地文件夹。
3. 双击 `公文排版助手V1_3_2.exe`。

普通用户不需要安装 Python、PySide6、python-docx 或 PyInstaller。

## 开发环境运行

在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python app/main.py
```

## 本地打包

在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_portable.ps1
```

打包成功后输出目录为：

```text
dist/公文排版助手V1_3_2
```
