## 1. 项目简介

公文排版助手 V1.2 是一款面向 Windows 平台的桌面便携软件，用于将导入或粘贴的文本按照公文参数重新排版，并导出为 `.docx` 文档。

软件支持本地运行，无需安装，适合个人公文整理、材料排版和基础格式统一场景。

## 2. 当前版本信息

- 产品名称：公文排版助手
- 当前版本：V1.2
- 发布形式：Windows 便携版
- 主程序路径：`dist/公文排版助手V1_2/公文排版助手V1_2.exe`

## 3. 核心功能

- 支持导入 `.docx`、`.txt`
- 支持在编辑区直接粘贴或输入文本
- 支持自动识别文档标题、一级标题、二级标题和正文
- 支持设置页边距、固定行距、字体、字号
- 支持加载本地字体并加入软件字体下拉菜单
- 支持删除软件中的字体选项
- 支持保存默认模板参数
- 支持保存默认导出文件夹
- 支持一键导出 `.docx`

## 4. V1.2 版本更新摘要

- 修正导出文档纸张大小为 A4（21.0 cm × 29.7 cm）
- 删除所有默认内置字体，仅保留仿宋
- 修改文档标题格式，删除标题前导空格并居中显示
- 调整软件界面字体与窗口尺寸，优化显示效果
- 优化字体、字号下拉框交互，点击显示框区域即可展开下拉菜单

## 5. 运行方式

直接打开以下程序即可运行：

```text
dist/公文排版助手V1_2/公文排版助手V1_2.exe
```

## 6. 开发环境运行

在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python app/main.py
```

## 7. 打包方式

```powershell
python -m pip install -r requirements.txt
.\build_portable.ps1
```

```text

```
