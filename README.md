## 1. 项目简介

公文排版助手 V1.1 是一款面向 Windows 平台的桌面便携软件，用于将导入或粘贴的文本按照公文参数进行重新排版，并导出为 `.docx` 文档。

本项目当前已完成可交付版本的开发与打包，适用于本地单机使用场景。

## 2. 版本信息

- 产品名称：公文排版助手
- 当前版本：V1.1
- 发布形式：Windows 便携版
- 主程序路径：`dist/公文排版助手V1_1/公文排版助手V1_1.exe`

## 3. 核心功能

- 支持导入 `.docx`、`.txt`
- 支持在编辑区直接粘贴或输入文本
- 支持自动识别文档标题、一级标题、二级标题和正文
- 支持设置页边距、固定行距、字体、字号
- 支持加载本地字体并加入软件字体下拉菜单
- 支持删除软件中的字体选项
- 支持保存默认模板参数
- 支持保存默认导出文件夹
- 支持一键导出 `.docx`

## 4. 运行方式

直接打开以下程序即可运行：

```text
dist/公文排版助手V1_1/公文排版助手V1_1.exe
```

本软件无需安装。

## 5. 开发环境运行

在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python app/main.py
```

## 6. 打包方式

在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
./build_portable.ps1
```

打包输出目录：

```text
dist/公文排版助手V1_1
```
