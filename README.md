## 1. 项目简介

公文排版助手 V1.3 是一款面向 Windows 平台的桌面便携软件，用于将导入或粘贴的文本按照公文参数重新排版，并导出为 `.docx` 文档。

软件支持本地运行，无需安装，适合个人公文整理、材料排版和基础格式统一场景。

## 2. 当前版本信息

- 产品名称：公文排版助手
- 当前版本：V1.3
- 发布形式：Windows 便携版
- 主程序路径：`dist_release/公文排版助手V1_3/公文排版助手V1_3.exe`

## 3. 核心功能

- 支持导入 `.docx`、`.txt`
- 支持在编辑区直接粘贴或输入文本
- 支持自动识别文档标题、一级标题、二级标题和正文
- 支持设置页边距、固定行距、字体、字号
- 支持加载本地字体并加入软件字体下拉菜单
- 支持删除软件中的字体选项
- 支持保存默认模板参数
- 支持保存默认导出文件夹
- 支持一键导出 `.docx`

## 4. V1.3 版本更新摘要

- 界面整体放大并重新校准控件尺寸、字体大小和区域间距
- 生成按钮改为深灰绿色 `#5F7450`
- 修复外接显示器、复制投影和不同 DPI 缩放下的标题与底部联系方式定位问题
- 默认字体调整为黑体和仿宋
- 一级标题默认字体为黑体，其余默认字体为仿宋
- 段落设置中的单位由 `pt` 调整为“磅”
- GitHub Actions 支持自动编译 Windows 便携版并通过 release 发布

## 5. 运行方式

直接打开以下程序即可运行：

```text
dist_release/公文排版助手V1_3/公文排版助手V1_3.exe
```

## 6. 开发环境运行

在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python app/main.py
```

## 7. 打包方式

在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
.\build_portable.ps1
```

打包输出目录：

```text
dist_release/公文排版助手V1_3
```

GitHub Release 中的 `公文排版助手V1_3-windows-portable.zip` 已包含运行所需依赖，普通 Windows 用户解压后双击 exe 即可运行。
